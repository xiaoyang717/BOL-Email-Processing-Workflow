## 物流

- 主要承运商：DHL E-Commerce；部分订单由合作方通过 PostNL / DPD 发出。
- DHL 追踪地址：`https://www.dhlecommerce.nl/nl/consument/track-en-trace`
- DHL 客服聊天：`https://my.dhlecommerce.nl/home/more/chat`
- 单号格式：DHL 为 `JVGL...`，PostNL 退货为 `3SBLCR...`。
- 大订单因尺寸 / 数量限制会拆成多个包裹，需一次性列出全部追踪号。
- 补发后通常 5 个工作日内送达；周五交给 DHL 的包裹周末不处理，下周二送达属合理预期。
- 追踪信息在不同渠道不一致时，以实际发货方（如 VVB/PostNL）的信息为准。

## bol.com 关键规则

- 顾客体验优先：能选择时，先让顾客在"退款 / 补发"之间选择。
- 不承诺做不到的事。
- 退款到账时间：数个工作日（取决于银行处理）。
- 绝不指责顾客。
- 包裹交给承运商后无法修改收货地址；确实无法收货可退款。
- 顾客需在 bol 规定时限内登记退货。
- 退款未到账：确认处理日期后引导顾客联系 bol.com 官方客服。
- 使用 bol.com 官方退货标签的包裹会寄往 bol 仓库，而不是商家退货地址；核验退货凭证时不要误判为异常。

## 退货流程

1. 顾客在 bol.com 发起退货。
2. 仓库或合作方收到退货。
3. 承运商（PostNL / DHL）记录的重量可作为件数证据。
4. 顾客声称退回数量多于重量所示时，要求补充证据：寄件证明、打包前照片、承运商确认。
5. 争议升级：连同证据（承运商重量、照片、实收件数）提交 bol.com 官方裁定。
6. 无寄件凭证且商家确实未收到时：说明暂无法核实并暂不退款，同时保留顾客后续补交凭证重新评估的通道。

## 退款原则

- 先询问顾客要退款还是补发，例外情况直接退款：首次使用即破损、墙板凹陷无法恢复、确认丢件、商品与描述不符、善意补偿。
- 善意退款可以超过实际损失金额。
- 破损 / 不符描述类退款：顾客无需退回商品，可自行保留或丢弃。
- 退款处理后在数个工作日内到账。

## 高频问题与处理口径

| 问题 | 处理口径 |
| --- | --- |
| 显示已签收但顾客未收到 | 建议查看邮箱、车库、邻居、房前屋后；找不到联系承运商 |
| 包裹丢失 | 提供退款或补发二选一；确认丢件可直接退款 |
| 包裹延迟 | 催促承运商，给出"预计"送达时间 |
| 取件点超时未取被退回 | 退款，或提供补发 / 退款二选一 |
| 拆单发货 | 说明承运商尺寸限制并列出全部追踪号 |
| 收到错误商品 | 可能是其他卖家，建议顾客核对订单并联系实际卖家 |
| 墙板脱落 / 起皱 | 先用附赠强力双面胶加固、让褶皱自然恢复；不满意再部分退款 |
| 退货数量争议 | 以承运商重量为准，要求补充证据，否则提交官方裁定 |
| 退款未到账 | 确认处理日期，仍未到账引导联系 bol.com 客服 |
| 发票请求 | 以邮件附件发送发票，需先确认订单号 |
